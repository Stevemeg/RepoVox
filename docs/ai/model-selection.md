## Memory, quantization and compatibility

Weight-only estimate = parameter count × bytes/parameter / 2^30; 4-bit estimate excludes scales, embeddings, workspace, fragmentation and KV. Baseline config has 48 layers, 8 KV heads, head dimension 128. BF16 KV = `2(K,V) * layers * KV_heads * head_dim * 2 bytes * sequence_tokens`; 16,384 tokens ≈3 GiB/sequence. Concurrency multiplies KV usage. Host RAM ≥32 GiB, read-only model disk ≥80 GiB; quantization build needs larger offline RAM. Not a guarantee of fit or latency.

Candidate serving paths: vLLM with owner-produced/pinned AWQ or supported GPTQ/compressed-tensor artifact; Qwen official cards show vLLM deployment, Devstral requires compatible Mistral tokenizer path. Exact engine/quantization versions selected after build tests, not `latest`. GGUF/llama.cpp alternative for smaller memory/CPU operation. Do not download arbitrary community conversions; quantization calibration must use licensed development data excluding held-out repositories. PEFT LoRA/QLoRA supported in principle by transformer families, but serving quantized base + adapter may need merge in BF16 then separately quantize; each variant re-evaluated. [vLLM formats](https://docs.vllm.ai/en/stable/features/quantization/) and [PEFT](https://huggingface.co/docs/peft/index), accessed 2026-10-08.

## Performance hypotheses and selection gate

Cost planning assumes **1,000 prefill tokens/s and 30 aggregate decoded tokens/s/GPU**, one active sequence, with 20s/video orchestration overhead. These are unverified workload hypotheses for the baseline, not vendor or local benchmarks. Compare 500/15 (slow) and 2,000/60 (fast) sensitivity; batch throughput cannot be treated as single-request speed. No predicted ranking by real latency without measurement. Long prompts, quantization, JSON grammar, adapter loading and CPU offload can reduce performance.

After Phase 0 approval, evaluate frozen unmodified bases on same prompt/schema/evidence, hardware, context caps and held-out set; log quality, peak VRAM, prefill/decode, TTFT, p50/p95, JSON validity and whole-video active seconds. Baseline wins only if [acceptance thresholds](evaluation-plan.md#acceptance-thresholds) pass. If baseline fails, compare ranked alternative under approved GPU budget; never silently promote it or call the unchanged base “custom-trained”. Latest upstream models can be added later through the same license/security/evaluation gate rather than unverified migration.
