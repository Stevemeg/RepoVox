# ADR-0013: Evaluation preparation evidence and sealed review

Status: Proposed for independent Phase 2B review. Date: 2026-10-12.

[Accepted gold/source-fact contract](0012-independent-gold-contract.md) · [Preparation](../development/evaluation-preparation.md) · [Storage](../development/evaluation-storage.md).

Accepted Phase 2 engineering supplies gold 1.0, source-fact 1.0 and corpus 2.0 with
source/hash/review/count checks. Actual preparation additionally needs a separate
candidate lifecycle, sealed labels, independently reviewed materialized adversarial
variants, genuine hidden authorship and physically checked custodian boundary.

Add `evaluation-candidates-1.0`, `eval-entry-preparation-1.0` and
`gold-review-receipt-1.0` as offline supplements. Preserve existing gold/scoring and
pipeline contracts. Freeze requires a protected packet and exact original evidence;
old flags alone cannot supply readiness. Revalidate copied model objects; exclude
self/unappointed/partial/unclear records from declared approved counts; label unverified
metadata counts separately from actual checked counts. Never lower existing thresholds.

Consequences: freeze callers must supply new preparation evidence; no official corpus
exists to migrate. Private receipts cover complete claim/edge membership and final
annotation digest, and materialized variants have their own parent-bound inventories.
Source/label edits require re-review. Actual POSIX ownership/mode/link/identity checks
complement authenticated operational access review, whose authority cannot be established
by hashes alone. Native Windows ACL equivalence remains unsupported. Synthetic tests
exercise full threshold freeze but create no rights, humans or official eligibility.

No model/training/paid service, source execution, official freeze, merge or Phase 3.
