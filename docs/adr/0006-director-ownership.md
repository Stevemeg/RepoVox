# ADR-006: Director model authority and ownership

Status: proposed · Date: 2026-10-08

Context: specialized model strategy must preserve independent grounding and truthful ownership.

Decision: Director consumes verified PKM/evidence, emits strict storyboard/narration/graph/scene/citation data, has no execution tools and cannot promote claim verdicts. An unchanged upstream base is labelled base-only; RepoVox owns its independently authored code/data/adapters subject to reviewed rights, not the upstream base or all training sources. Base license and dataset/adapter provenance separate. No scratch-training claim.

Alternatives: train foundation model from scratch is financially unrealistic; model self-verification lacks independent support; generated renderer code introduces execution risk; prompt branding alone is not specialization.

Consequences: metadata/license manifests, independent verifier and safe visual schemas required; uncertain facts remain qualified. Reverse only through owner-approved evidence/product policy, never by model output. [Director](../ai/director-architecture.md), [training](../ai/training-strategy.md).
