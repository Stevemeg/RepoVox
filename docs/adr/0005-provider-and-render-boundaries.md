# ADR-005: Provider adapters and trusted visual templates

Status: proposed · Date: 2026-10-08

Context: quality/prices/terms change; model output cannot become executable scene code.

Decision: bounded typed LLM/TTS adapters, usage/operation records. Cost candidates Haiku 4.5 and Polly Neural; production IDs after evaluation/terms review. Trusted Remotion scenes with FFmpeg encode/probe; no dynamic JSX/HTML/JS/commands/repository remote assets.

Alternatives: direct SDK calls scatter privacy/budget/retry logic; local inference adds hardware/quality burden; generated code too risky; FFmpeg-only slides cheaper/less expressive. Explicit provider change invalidates relevant cache versions, no silent fallback.

Consequences: schema/template tests, pronunciation checks and Chromium sandbox validation precede launch. License cost may have monthly minimum. Revisit local inference if privacy/volume economics warrant it.

Evidence: [contracts](../architecture/pipeline.md), [cost/license](../operations/cost-model.md), [Remotion licensing](https://www.remotion.dev/docs/license/pricing).
